# Thesis Defense Deck — GeoAI Digital Twin (CGSM)

Presentation-style dashboard for Lina Quintero Fonseca's master's thesis proposal
defense (Master's in Geomatics, Universidad Nacional de Colombia). Built on
Next.js 16 + React 19 + Tailwind v4 + motion, using the official UNAL
institutional templates (Ancízar typeface, crest, palette).

## Run

```bash
npm run dev      # http://localhost:3000
npm run build && npm run start   # production
```

## Controls

- **→ / Space / PageDn** next · **← / PageUp** previous · **Home / End** first / last
- **N** presenter notes (Spanish speaker script) · **R** start/stop rehearsal timer ·
  **G** overview grid · **T** switch theme (green ⇄ purple) · **F** fullscreen ·
  **Esc** close panels
- On-screen: bottom control bar (arrows, counter, notes, overview, theme, fullscreen),
  top progress rail, and a clickable dot rail.

### Rehearsal timer

Open presenter notes (**N**) and press **Ensayo** (or key **R**). The timer banks the time
spent on each slide as you advance, shows the current-slide time (◷), the running total
(Σ) against the **11:00** target (color-coded), and a per-slide breakdown via the
**Tiempos** toggle. A live total also shows in the bottom control bar while rehearsing.
Pausing saves the run to `localStorage` (`deck_rehearsal`) so you can compare against your
last rehearsal.

The Spanish speaker script also lives in [`SPEAKER_NOTES_ES.md`](SPEAKER_NOTES_ES.md)
for printing. Both come from the `SCRIPT` object at the top of `thesis-deck.tsx`
(single source of truth).

## Editing

- **Slides + content:** `src/components/presentation/thesis-deck.tsx` — 12 slides,
  all text in English, composed from reusable primitives.
- **Cover credits:** edit the `PRESENTER` / `ADVISOR` / `DEFENSE_DATE` constants
  at the top of `thesis-deck.tsx` (advisor + date are placeholders to fill in).
- **Default theme:** `<Deck.Root brand="verde">` — change to `"morado"` for purple
  by default. Green is the default because the thesis subject is mangrove /
  coastal ecology.

## Architecture (`src/components/deck/`)

Composable deck per the components.build spec:

- `deck.tsx` — `Deck.Root`: slide state, keyboard nav, 16:9 letterboxed stage,
  brand/overview context.
- `slide.tsx` — `Deck.Slide`: full-bleed slide; `variant` (`cover` / `content` /
  `closing`) selects the institutional background for the active palette.
- `deck-nav.tsx`, `deck-overview.tsx` — controls and the jump-to grid.
- `primitives.tsx` — `SlideHeader`, `StatCard`, `NumberedItem`, `Panel`,
  `FeatureItem`, `BulletList`, `Tag`, `Eyebrow`, `Lead`, `IconBadge`.
- Brand tokens (palette per theme) live in `src/app/globals.css`
  (`[data-brand="verde"]` / `[data-brand="morado"]`).

## Structure (11-minute talk, ~1 slide/min)

- **Context & objectives (≈50%, slides 1–6):** cover · context/problem · study area
  & data readiness (map) · knowledge gap · question & objectives · internal-coherence
  checklist.
- **Methods & results (≈40%, slides 7–11):** operational framework (figure) · datacube
  + one prioritized route (Random Forest) · classification/floods & evaluation metrics
  (OA·F1·IoU·RMSE·R²) · end-to-end worked example (Rinconada) · results / Digital Twin
  / timeline.
- Slide 12: closing.
- **Slide 13 (backup):** feasibility — timeline & budget, shown only for Q&A. Budget
  detail and rationale live in [`PRESUPUESTO_ES.md`](PRESUPUESTO_ES.md).

## Institutional assets & figures
